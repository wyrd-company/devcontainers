OpenBao Agent runs under s6-overlay as `root` by default so that its credential and token stay out of the remote user's reach; `serviceUser` overrides this. Supply a readable Agent configuration at `/etc/openbao/agent.hcl`, or at `configPath`, and restart the service with `sudo /command/s6-svc -r /run/service/openbao-agent` after changing it. To give a secret to another Feature's service, add a `template` with the destination `/run/openbao/secrets/<feature-id>.env`; the service waits for that file and loads its `NAME=value` lines at start.
