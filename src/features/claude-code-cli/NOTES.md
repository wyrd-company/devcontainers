Runs Anthropic's native installer as the resolved Dev Container user and symlinks its user-owned executable into `/usr/local/bin/claude`.

Example usage:

```json
{
  "features": {
    "ghcr.io/wyrd-company/devcontainers/claude-code-cli:1": {}
  }
}
```
