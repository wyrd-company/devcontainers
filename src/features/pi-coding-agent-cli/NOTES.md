Installs the npm-distributed Pi coding agent beneath the resolved Dev Container user's `${HOME}/.local` directory.

```json
{
  "features": {
    "ghcr.io/wyrd-company/devcontainers/pi-coding-agent-cli:1": {}
  }
}
```

Logo: the pi mark from [pi.dev/favicon.svg](https://pi.dev/favicon.svg), in its light-theme color. The [pi repository](https://github.com/earendil-works/pi) is MIT and publishes no trademark terms. Used here only to identify the upstream project.
