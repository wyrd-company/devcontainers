Installs the npm-distributed Pi coding agent beneath the resolved Dev Container user's `${HOME}/.local` directory.

```json
{
  "features": {
    "ghcr.io/wyrd-company/devcontainers/pi-coding-agent-cli:1": {}
  }
}
```
